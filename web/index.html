Kills this week

A kill counts when your log shows the boss die (“You have slain…”, “…has been slain by…”), so you need to be in the zone. Lockouts reset Tuesdays at 8am Pacific. After a kill, a raid can be cleared again every 18 hours for one extra loot piece per boss.

Inventory

In game type /outputfile inventory. EQL writes Name_server-Inventory.txt to its game folder. The app reads it from there by itself, or import it here. Bags, bank, worn items and the key ring all count, including upgraded (+1…) and Exaltation versions.

How items tick off

Items you loot or receive tick themselves. Ground pick-ups, combines and hand-ins usually don't show in the log, so tick those yourself.

Deaths

A recap covers the last minute before each death: every hit, miss, spell and damage-over-time tick on you, heals you got, spells you resisted and stuns. The log has no hit point numbers, so it shows damage and heals rather than your health bar.

Race unlocks

From EQLWiki: a race unlocks through its achievement (Untapped Potential → Races). Faction races need maximum faction with each listed faction; they don't all have to be maxed at once. A faction ticks here when any of your characters' logs say “Your faction standing with … could not possibly get any better.” Starting a character as a race, or a Race Unlock Token, also unlocks it: tick Unlocked for those. Unlocks are account-wide, so they're shared by all your characters. Ways to raise each faction: Alanna's Race Unlock Guide on EQLWiki ↗

Faction changes

The log only shows changes (“…has been adjusted by -3”), not your absolute standing. Click Set and enter a faction's current value once (from the in-game faction window or a faction calculator). The app then keeps an estimated value and standing from there. Standing names use classic EQ thresholds.

Overlays

Always-on-top windows that sit over EverQuest Legends. Run the game in borderless windowed mode so they stay visible. Drag a window to move it, drag its bottom-right corner (or Ctrl + mouse wheel) to resize it, and right-click it for the same options as here. An overlay that's on opens again next time you start the app.

Settings

In game type /log on. Files look like eqlog_Name_server.txt. For exact item counts type /outputfile inventory now and then — the app picks it up automatically.

Crawl leaderboard

Each run is sent with the dungeon, difficulty, time, solo or group, a picture of the crawl timer window, your classes and your group members' classes (from /who, or guessed from the spells and skills they use), and the run's log lines so the site can check the time. Your character and server come from your log file name.

Your classes, per character

Needed to send runs to the leaderboard. Each character (and server) has its own. If you change loadout, pick them again, or type /who on yourself in game: a newer /who that lists all three classes wins. To fix one run (or a group member's classes), open the run on the Crawls tab and use Edit.
