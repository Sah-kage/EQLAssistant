How items tick off

Items you loot or receive tick themselves. Ground pick-ups, combines and hand-ins usually don't show in the log, so tick those yourself.

Faction changes

The log only shows changes (“…has been adjusted by -3”), not your absolute standing. Click Set and enter a faction's current value once (from the in-game faction window or a faction calculator). The app then keeps an estimated value and standing from there. Standing names use classic EQ thresholds.

Overlays

Always-on-top windows that sit over EverQuest Legends. Run the game in borderless windowed mode so they stay visible. Drag a window to move it, drag its bottom-right corner (or Ctrl + mouse wheel) to resize it, and right-click it for the same options as here. An overlay that's on opens again next time you start the app.

Settings

In game type /log on. Files look like eqlog_Name_server.txt. For exact item counts type /outputfile inventory now and then — the app picks it up automatically.

Closes the app and the in-game overlay.
